# Seven7Studios — Portfólio

Site estático de apresentação dos projetos de desenvolvimento web da Seven7Studios.

## Arquivos ativos

- `index.html`: estrutura, conteúdo, metadados SEO e dados estruturados.
- `portfolio.css`: identidade visual, layout responsivo e estilos de impressão.
- `portfolio.js`: navegação mobile, ano dinâmico e impressão.
- `favicon.svg`: ícone do site.
- `og-cover.svg`: imagem de compartilhamento social.
- `robots.txt` e `sitemap.xml`: arquivos básicos para indexação.

## Desenvolvimento local

Abra `index.html` no navegador ou use um servidor estático local.

Não há etapa de build nem dependências npm neste site. O portfólio é estático e não utiliza banco de dados. Supabase aparece apenas como tecnologia usada no projeto Caixa Izaias, não como integração deste site.

## Observação sobre arquivos antigos

Os arquivos `style.css` e `script.js`, assim como mídias que já estavam no repositório, foram preservados por segurança. A página publicada atualmente carrega apenas `portfolio.css` e `portfolio.js`. Esses arquivos antigos podem ser arquivados ou removidos depois de confirmar que não são mais necessários para outro conteúdo.
